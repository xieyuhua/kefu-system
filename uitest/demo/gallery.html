示例场景总览

这些页面都按 Vue/Element 打包后的样子 写：hash 类名、data-v-* 作用域属性、组件库自动 id，几乎没有稳定 id —— 专门用来验证「重建安全定位」和各类动作。

1基础表单（新建服务商品）

最典型的表单：文本、数字、下拉、富文本、文件上传、保存按钮。带稳定 id，适合入门。

表单填写下拉选择上传

2登录页

账号/密码 + 记住密码勾选 + 登录按钮，带前置校验。字段全靠表单项标题定位。

表单项标题定位勾选断言提示语

3列表 / 搜索 / 批量 / 行内操作

关键词搜索 + 状态筛选 + 结果计数、全选与批量上架、每行的编辑/删除。查询按钮带 data-testid，可对比"有锚点 vs 没锚点"。

表格行内按钮data-testid结果计数断言

4弹窗表单 / 下拉 / 日期 / 开关

点「新建活动」弹窗，填名称/类型/起止日期、切「是否上架」开关，保存后列表新增一行。先点保存能验证必填校验。

弹窗内定位日期输入switch 开关必填校验

5多步向导 / 校验

填写信息 → 确认提交 → 完成。手机号为空点「下一步」会报错，用来验证校验提示与跨步骤断言。

多步流程校验提示汇总断言

6标签页 / 开关 / 单选 / 富文本 / 上传

基础设置与高级设置两个 tab，含营业状态开关、店铺类型单选、欢迎语富文本、Logo 上传。

tab 切换开关单选上传

7打包版本 A

商品表单 + 表格。记录「版本 A 的定位」，用版本 B 回放，验证重新打包后依然命中。

hash 类名自动 id跨版本验证

8打包版本 B（模拟重新打包）

所有 hash/id 都变了，还多了一层包装 div、表格多一列、行内按钮顺序调换。

结构变化顺序调换跨版本验证
怎么用：在控制台「录制」里新建录制，把起始页填成上面任意场景地址，用浏览器插件操作一遍即可。
想一次性验证所有场景：在项目目录执行 go run ./cmd/scenarios， 它会自动为每个场景建录制、跑执行、逐条断言，最后打印结果表。
